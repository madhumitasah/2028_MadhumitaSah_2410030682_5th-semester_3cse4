## About the Internship

The internship provided practical exposure to software development through work on **Task2Grab**, a task-based rewards platform that enables users to discover dynamically available campaigns or tasks, complete eligible activities, and receive rewards when successful completion is recognized.

My primary responsibilities were centred on the **wallet system** and **task listing functionality**. I worked on API integration for task listing, rewards, and wallet-related information, contributed to displaying reward and wallet information in the interface, handled application state for dynamic data, and translated provided Figma designs into React Native code for selected application areas.

---

## My Scope of Work

- Planning and understanding assigned application requirements
- Task listing functionality and presentation of task/campaign information
- Primary work on the wallet system
- API integration for task listing, reward-related information and wallet-related information
- Displaying reward and wallet information in the user interface
- Working with application state for dynamic data
- Translating provided Figma designs into React Native code
- Contribution to selected parts of the mobile application and the broader Task2Grab project

**Not part of my individual scope:** independent development of the complete application architecture or backend, the website/login page, and navigation/AsyncStorage-related functionality — these were handled by other team members.
